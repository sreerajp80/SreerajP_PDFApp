# Change Log — App Launcher Icon v2 (Reader/Editor + Printer)

Implements plan: `plans/20260718_184500_app_icon_v2.md`.
Supersedes the v1 icon (`change_log/20260718_183000_app_icon.md`).

## Why

The v1 icon (document emerging from a printer) read only as a **PDF printer**
at small sizes. The user asked for an icon that says **read, edit, and print**.

## What changed

Reworked the `Draw-Art` layout in `tool/generate_icon.ps1` and regenerated all
assets. New composition (agreed with user: "PDF page + pen, small printer"):

- **Hero PDF sheet** (reader) — larger and raised, with content lines and a bold
  **"PDF"** label; now the dominant element.
- **Pen across the lower sheet** (editor) — amber barrel, light nib with a slate
  tip, darker end cap; drawn by a new `Draw-Pen` helper.
- **Small printer at the base** (printer) — shrunk and lowered; the sheet
  overlaps its top so it still reads as "print".
- Slate-blue theme gradient tile and colors unchanged.

## Files modified

- `tool/generate_icon.ps1` — new `Draw-Pen` helper + reworked `Draw-Art` layout.
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher_foreground.png`
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher_background.png`
- `assets/branding/ic_launcher_1024.png` — regenerated master.

No change to `AndroidManifest.xml` or `mipmap-anydpi-v26/ic_launcher.xml`
(unchanged from v1). File names and sizes are identical to v1 — only pixels
changed — so the Android resource merge proven in the v1 build still holds.

## Verification

- Ran `tool/generate_icon.ps1`; all densities + the 1024 master regenerated.
- Checked the 1024 master, a 48px render, and a composited adaptive preview
  against the circular launcher mask: the page + pen read clearly, the printer
  stays supporting, and everything sits inside the adaptive safe zone.
- Resource structure is unchanged from v1 (same filenames/paths), which already
  built into the APK successfully.

## Note for testing

Launchers cache the old icon; do a fresh reinstall
(`flutter install --flavor dev`) to see the new icon on a device/emulator.
