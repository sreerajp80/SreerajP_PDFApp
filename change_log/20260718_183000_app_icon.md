# Change Log — App Launcher Icon

Implements plan: `plans/20260718_182000_app_icon.md`.

## What changed

Replaced the default Flutter launcher icon with a branded **adaptive icon**.

- **Design:** a white PDF document sheet (dog-eared top-right corner, two
  content lines, a bold "PDF" label) emerging from a small white printer, on a
  slate-blue gradient tile. Slate matches the app theme seed `#3D5A80`
  (`lib/app/theme/tokens.dart`). A small amber status LED adds a touch of color.
- **Concept + color** were chosen by the user: "document + printer", "match app
  theme".

## Files added

- `tool/generate_icon.ps1` — offline icon generator (PowerShell + .NET
  `System.Drawing`). Re-run to tweak the design; no ImageMagick/fonts required
  (falls back to drawn bars if no font).
- `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` — adaptive icon
  (references the foreground + background layers).
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher_foreground.png`
  — white document + printer artwork, sized into the adaptive safe zone.
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher_background.png`
  — slate-blue gradient background layer.
- `assets/branding/ic_launcher_1024.png` — 1024px master for the Play Store
  listing (not bundled in the app).

## Files modified

- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`
  — replaced the default white square with the new branded art on a rounded tile
  (legacy/fallback; every supported device (minSdk 26) uses the adaptive icon).

No `AndroidManifest.xml` change was needed — it already points at
`@mipmap/ic_launcher`, and the new `mipmap-anydpi-v26` variant makes Android use
the adaptive icon automatically.

## Verification

- Ran `tool/generate_icon.ps1`; all densities + the 1024 master produced.
- Visually checked the 1024 master and a composited adaptive preview against a
  circular launcher mask — the art sits within the safe zone and reads clearly.
- Built the debug APK; Android resource merge succeeded. Confirmed the APK
  contains `mipmap-anydpi-v26/ic_launcher.xml` plus foreground/background/legacy
  PNGs for all five densities.
  (Note: `flutter build apk --debug` reports "failed to produce an .apk" only
  because this project uses `dev`/`prod` flavors; the flavored APKs, including
  the new icons, build fine.)
