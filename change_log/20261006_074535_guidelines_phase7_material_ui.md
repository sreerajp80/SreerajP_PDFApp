# Change log — Guidelines Phase 7: move to `material_ui` / `cupertino_ui`

Implements Phase 7 of [../plans/20261005_202751_guideline_compliance_audit.md](../plans/20261005_202751_guideline_compliance_audit.md)
(finding F1, engineering standard §6.1, `guideline.md` §4).

## What changed

- `pubspec.yaml` / `pubspec.lock` — direct dependencies `material_ui: ^1.5.0` and
  `cupertino_ui: ^1.1.1` (caret constraints, added with `flutter pub add`). Both were already
  transitive through `pdfrx`. Checked: BSD-3-Clause, published by the Flutter team, no network
  packages among their dependencies.
- 100 Dart files in `lib/` and `test/` — `package:flutter/material.dart` and
  `package:flutter/cupertino.dart` replaced by `package:material_ui/material_ui.dart` /
  `package:cupertino_ui/cupertino_ui.dart`, using `dart fix --apply --code=migrate_design_widgets`
  (101 fixes). Imports sorted afterwards. No old imports remain.
- `GlobalMaterialLocalizations` / `GlobalCupertinoLocalizations` now come from `material_ui` /
  `cupertino_ui`. Files that import `flutter_localizations` now take only
  `show GlobalWidgetsLocalizations` (the §8.3.1 pattern), or drop the import when unused.
  Test files that use `GlobalCupertinoLocalizations` import `cupertino_ui`.
- `lib/app/app.dart` — delegates are now `AppLocalizations.delegate`, the three Sanskrit fallback
  delegates (first, so they win for `sa`), then `...GlobalMaterialLocalizations.delegates`
  (Material + Cupertino + Widgets), as §8.1 shows.
- `CLAUDE.md`, `AGENTS.md`, `.agents/AGENTS.md` — the "open migration item" note replaced by the
  rule now in force (kept in sync).
- `docs/dependencies.md` — `material_ui` and `cupertino_ui` listed; `flutter_localizations` row
  corrected (it serves en, ml and sa). `docs/architecture.md` §21 — removed the two risks fixed
  in Phases 3 and 7 (raw strings on the Features screen, old Material imports) and updated the
  opened-copies risk.

## Tests

- `flutter analyze`: no issues. `flutter test`: 448 passed.
  `flutter build apk --flavor dev --debug`: built.

## Notes

- The generated `lib/l10n/app_localizations.dart` still lists the `flutter_localizations` copies in
  its own `localizationsDelegates` constant. That file is generated by `flutter gen-l10n` and is
  not edited by hand; the app itself uses the explicit list in `app.dart`.
