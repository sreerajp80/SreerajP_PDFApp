# Change log — Guidelines Phase 8: ARB key prefixes

Implements Phase 8 of [../plans/20261005_202751_guideline_compliance_audit.md](../plans/20261005_202751_guideline_compliance_audit.md)
(finding F14), with the user's choice B1 (rename all keys).

## What changed

- `lib/l10n/app_en.arb`, `app_ml.arb`, `app_sa.arb` — 615 keys renamed to the engineering
  standard §8.6 category prefixes (`action…`, `label…`, `title…`, `tab…`, `tooltip…`, `desc…`,
  `help…`, `empty…`, `error…`, `body…`). Every `@key` description moved with its key. Values are
  unchanged except where listed below. Generated localizations regenerated.
- Kept as they are: `madeWithLove` and `madeWithLoveA11y` — `guideline.md` §1.7 fixes these
  names.
- 750 uses in 56 Dart files updated. Only uses on a localizations object were renamed (`l10n.`,
  `en.`, `AppLocalizations.of(…).`, `lookupAppLocalizations(…).`), because several old key names
  are also real methods or enum values (`goToPage`, `fitWidth`, `zoomIn`).
- How names were chosen: by the old suffix (`…Action` → `action…`, `…Title` → `title…`,
  `…Tooltip` → `tooltip…`, `…Label`/`…Hint` → `label…`, `…Subtitle`/`…Detail` → `desc…`,
  `…Message`/`…Body` → `body…`, `…Help` → `help…`, `…Failed`/`…Error` → `error…`, `no…` →
  `empty…`), otherwise by the text (a short label → `label…`, a sentence → `desc…`).

### Labels shortened to the budget (§8.6: "choose a shorter word")

48 UI labels did not fit the short-label limit. Three are dynamic text and are now `desc…`
(`descPageCount`, `descResolution`, `descBatchProgress`); one is a sentence hint and is now
`helpOrganize`. For the other 44, the English was shortened to 20 characters or fewer (sentence
case), for example "Clear Recent Files History" → "Clear recent files", "Default PDF Viewer
('Open with')" → "Default PDF viewer", "Protect with password" → "Add password". In four of
them the Malayalam or Sanskrit was too long as well, so those were shortened too:

| Key | ml | sa |
|---|---|---|
| `titleImportUnsupportedText` | പിന്തുണയില്ലാത്ത അക്ഷരങ്ങൾ | असमर्थितानि अक्षराणि |
| `titlePermSendShare` | പങ്കിട്ടവ സ്വീകരിക്കൽ | वितीर्णस्वीकरणम् |
| `titlePermViewPdf` | PDF തുറക്കുന്ന ആപ്പ് | मूल-PDF-दर्शकम् |
| `tooltipMalayalamHelper` | മലയാളം ടൈപ്പിംഗ് സഹായി | मलयाललेखनसाहाय्यम् |

## Tests

- `test/l10n/label_length_test.dart` — new test: every key has a category prefix (except the two
  fixed badge names). The length test now checks far more keys, because they carry short prefixes.
- `test/l10n/translation_parity_test.dart` — allow-list updated to the new names.
- 10 widget tests updated to the shortened English text.
- `flutter analyze`: no issues. `flutter test`: 449 passed.

## Needs native-reader review

- The four Malayalam and Sanskrit strings in the table above.

## Left for later (not in this plan)

- Many other English labels still use Title Case ("Remember Recent Files" style). §8.6 asks for
  sentence case in English. Only the 44 shortened labels were changed here.
