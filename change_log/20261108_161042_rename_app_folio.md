# Change log: rename the app to Folio / ഗ്രന്ഥം / ग्रन्थः

Implements: [plans/20261108_161042_rename_app_folio.md](../plans/20261108_161042_rename_app_folio.md)

## What changed

The app is now called **Folio** in English, **ഗ്രന്ഥം** in Malayalam and **ग्रन्थः** in Sanskrit.
The dev flavor adds " Dev". The package id `in.sreerajp.pdfapp` did not change.

**Android**
- `android/app/src/main/res/values*/strings.xml` and `android/app/src/dev/res/values*/strings.xml`:
  new launcher names. The print service name is "Folio"; the printer is "Save as PDF (Folio)".
- `TtsHandler.kt`: fallback notification title is "Folio". `PdfPrintService.kt` and
  `AndroidManifest.xml`: comments only.

**Config and code**
- `assets/config/app_config.json`: `appName` en/ml/sa. The launcher names still match it (guideline.md §1.8).
- `lib/core/config/app_config.dart`: fallback app name.
- `lib/features/reading/data/tts_service.dart`: fallback TTS title. `lib/main.dart`: start-up log line.
  `lib/features/settings/presentation/features_screen.dart`: doc comment.

**Localized text**
- `lib/l10n/app_en.arb`: `titleApp`, `titleHome` and all help/description texts use "Folio".
- `lib/l10n/app_ml.arb`: `titleApp`/`titleHome` = "ഗ്രന്ഥം". In sentences: "ഗ്രന്ഥം ആപ്പ്" with the
  normal suffix (ആപ്പിനെ, ആപ്പിലെ, ആപ്പിന്റെ).
- `lib/l10n/app_sa.arb`: `titleApp`/`titleHome` = "ग्रन्थः". In sentences: "ग्रन्थ-अनुप्रयोग" with the
  needed case ending (अनुप्रयोगः, अनुप्रयोगं, अनुप्रयोगे, अनुप्रयोगस्य). In `helpPrivacyStorageIntro`,
  "निर्मितम्" became "निर्मितः" to agree with the masculine अनुप्रयोगः.
- Generated `lib/l10n/app_localizations*.dart` files were rebuilt with `flutter gen-l10n`.

**Tests**
- `test/core/config/app_config_test.dart`, `test/features/settings/presentation/settings_screen_test.dart`,
  `test/features/help/presentation/pdf_printer_help_screen_test.dart`,
  `test/features/help/presentation/unicode_printing_help_screen_test.dart`: expect the new name.

**Docs**
- `pubspec.yaml` description, `README.md`, `CHANGELOG.md` (new Unreleased entry), `CLAUDE.md`,
  `AGENTS.md`, `.agents/AGENTS.md` (kept in sync), and `docs/` files `PROJECT_PROFILE.md`,
  `features.md`, `architecture.md`, `release_process.md`, `security.md`, `project_structure.md`,
  `workflow_rules.md`, `dependencies.md`, `pdf_idea.md`, `feature_analysis_and_roadmap.md`.
- `docs/PROJECT_PROFILE.md` has a new "Google Play store title" row:
  `en-IN` "Folio: Offline PDF Reader", `ml-IN` "ഗ്രന്ഥം: ഓഫ്‌ലൈൻ PDF റീഡർ".

## Small differences from the plan

- **Help steps that name an on-screen label use "Folio" in all languages.** The print service name
  only exists in English (`values/strings.xml`), so Android's Print services list and the print
  dialog show "Folio" even on a Malayalam phone. The Malayalam and Sanskrit steps
  `helpPdfPrinterStep3` and `helpUnicodePrintingStep3` therefore say "Folio", so they match the screen.
- **Store-listing language:** `docs/PROJECT_PROFILE.md` said Google Play `en-US`; it now says `en-IN`,
  as the user asked for `en-IN` and `ml-IN` titles.

## Not changed

- `docs/implementation_plan.md`, `docs/implementation_progress.md`, older `CHANGELOG.md` entries and
  all older `plans/` and `change_log/` files keep the old name (point-in-time records).
- `docs/guidelines/` (submodule): not touched.

## Checks

- `flutter gen-l10n`: done. `dart format .`: done. `flutter analyze`: no issues.
- `flutter test`: all 455 tests passed (including translation parity and label length).
- Not checked on a device yet: launcher label, print service name, About screen.

## Needs native-reader review

- Malayalam: "ഗ്രന്ഥം", the store title "ഗ്രന്ഥം: ഓഫ്‌ലൈൻ PDF റീഡർ" and the help sentences with "ഗ്രന്ഥം ആപ്പ്…".
- Sanskrit: "ग्रन्थः" and the "ग्रन्थ-अनुप्रयोग…" sentences. The hyphen keeps the name visible; strict
  sandhi would give "ग्रन्थानुप्रयोग…". A reviewer may prefer that.

## Possible follow-up

  on those phones. Then the two help steps above should change back to the local name.
