# Change log — Guidelines Phase 10: language-pack terminology in existing translations

Implements Phase 10 of [../plans/20261005_202751_guideline_compliance_audit.md](../plans/20261005_202751_guideline_compliance_audit.md)
(added during Phase 3 and approved by the user). Rules: language pack
`sanskrit_malayalam.md` §4.1 (Sanskrit) and §4.2 (Malayalam).

## What changed

### Sanskrit (`lib/l10n/app_sa.arb`) — Hindi-marker gate now passes
The pack's gate matches some letter sequences anywhere in a word, so five real Sanskrit words were
flagged. They were reworded with the same meaning:

| Key | Before | After |
|---|---|---|
| `helpReopenFailed` | … पुनः उद्घाटयितुं शक्याः। | … पुनः उद्घाटयितुं शक्यन्ते। |
| `helpTtsStep3` | … वाक्यावसानविरामं … | … वाक्यसमाप्तिविरामं … |
| `helpSignaturesStep3` | … विश्वस्तसङ्ग्रहे योजयितुं शक्यते। | … विश्वस्तसङ्ग्रहस्य अन्तः योजयितुं शक्यते। |
| `titlePermNoBroadStorage` | विस्तृतसङ्ग्रहानुमतिराहित्यम् | विस्तृतसङ्ग्रहः नास्ति |
| `titleTtsSentencePause` | वाक्यावसाने विरामः | वाक्यसमाप्तौ विरामः |

### Malayalam (`lib/l10n/app_ml.arb`) — banned loanwords replaced
103 strings rewritten (the plan counted about 99; `പ്രിന്റർ` "printer" and the other spelling
`സെറ്റിങ്സ്` "settings" were included for consistency). No `പേജ്`, `പ്രിന്റ്`, `പ്രിന്റർ`,
`സേവ്`, `എക്സ്പോർട്ട്`, `നമ്പർ`, `സെറ്റിംഗ്/സെറ്റിങ്`, or `കോപ്പി` remains. Pack terms used:
`താൾ` (page), `അച്ചടി` / `അച്ചടിക്കുക` (print), `അച്ചടിയന്ത്രം` (printer), `സൂക്ഷിക്കുക`
(save), `കയറ്റുമതി` (export), `സംഖ്യ` (number), `ക്രമീകരണങ്ങൾ` (settings). The same terms
are used in the Phase 3 Features text, so the app now reads consistently.

Also fixed while there: `labelMetadataProducer` said "സേവ് ചെയ്തത്" ("saved by"); it now says
"നിർമ്മിച്ച പ്രോഗ്രാം" (the program that made the PDF), which is what "Producer" means.
