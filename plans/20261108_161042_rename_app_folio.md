# Rename the app to Folio / ഗ്രന്ഥം / ग्रन्थः

**Status:** completed

## Issue

Today the app is named "SreerajP PDF App" in English, "ശ്രീരാജ് പി പിഡിഎഫ് ആപ്പ്" in Malayalam
and "श्रीराज पी पीडीएफ अनुप्रयोगः" in Sanskrit. People don't search for a personal name, and the
name does not say what the app is. The user has picked a new name:

| Place | English | Malayalam | Sanskrit |
|---|---|---|---|
| Launcher / in-app name | Folio | ഗ്രന്ഥം | ग्रन्थः |
| Dev flavor launcher name | Folio Dev | ഗ്രന്ഥം Dev | ग्रन्थः Dev |
| Google Play store title | `en-IN`: Folio: Offline PDF Reader | `ml-IN`: ഗ്രന്ഥം: ഓഫ്‌ലൈൻ PDF റീഡർ | (Play has no Sanskrit listing) |

The store titles are typed into Play Console by hand. This plan only records them in the docs.

## What does NOT change

- Package / application id `in.sreerajp.pdfapp` (and `.dev`). It can never change once the app is on Play.
- The Kotlin package folder `in/sreerajp/pdfapp/`.
- Old files in `plans/` and `change_log/`. They are history and keep the old name.
- The About author, developer and copyright fields.

## Files to change

**Android (launcher and print service names)**
- `android/app/src/main/res/values/strings.xml`: `app_name` → Folio; `print_service_name` → Folio;
  `print_service_description` and `printer_name_save_pdf` → use "Folio".
- `android/app/src/main/res/values-ml/strings.xml`: `app_name` → ഗ്രന്ഥം
- `android/app/src/main/res/values-sa/strings.xml`: `app_name` → ग्रन्थः
- `android/app/src/dev/res/values/strings.xml`, `values-ml/`, `values-sa/`: the same name + " Dev"
- `android/app/src/main/kotlin/in/sreerajp/pdfapp/TtsHandler.kt`: fallback title → "Folio"
- `android/app/src/main/kotlin/in/sreerajp/pdfapp/PdfPrintService.kt`, `android/app/src/main/AndroidManifest.xml`: comments only

**Config (single source of truth for About)**
- `assets/config/app_config.json`: `appName` en/ml/sa → the new names
- `lib/core/config/app_config.dart`: fallback `appName` → "Folio"

**Localized text (ARB files, then `flutter gen-l10n`)**
- `lib/l10n/app_en.arb`: `titleApp`, `titleHome` → "Folio". Every help/description text that says
  "SreerajP PDF App" → "Folio".
- `lib/l10n/app_ml.arb`: `titleApp`, `titleHome` → "ഗ്രന്ഥം". In sentences, write "ഗ്രന്ഥം ആപ്പ്" with
  the normal suffix (for example "ഗ്രന്ഥം ആപ്പിലെ"). This is needed because "ഗ്രന്ഥത്തിലെ" on its own
  would read as "in the book", not "in the app".
- `lib/l10n/app_sa.arb`: `titleApp`, `titleHome` → "ग्रन्थः". In sentences, use the compound
  "ग्रन्थ-अनुप्रयोग" + the case ending (for example "ग्रन्थ-अनुप्रयोगस्य", "ग्रन्थ-अनुप्रयोगः"), for the
  same reason.
- The generated `lib/l10n/app_localizations*.dart` files are rebuilt by `flutter gen-l10n`, not
  edited by hand.

**Dart code**
- `lib/features/reading/data/tts_service.dart`: fallback notification title → "Folio"
- `lib/main.dart`: start-up log line → "Starting Folio."
- `lib/features/settings/presentation/features_screen.dart`: doc comment only

**Tests**
- `test/core/config/app_config_test.dart`
- `test/features/settings/presentation/settings_screen_test.dart`
- `test/features/help/presentation/pdf_printer_help_screen_test.dart`
- `test/features/help/presentation/unicode_printing_help_screen_test.dart`

**Docs and metadata**
- `pubspec.yaml`: `description`
- `README.md`, `docs/PROJECT_PROFILE.md` (display names, and a new "Store titles" row with the
  en-IN and ml-IN titles), `docs/features.md`, `docs/architecture.md`, `docs/release_process.md`,
  `docs/security.md`, `docs/project_structure.md`, `docs/workflow_rules.md`, `docs/dependencies.md`,
  `docs/pdf_idea.md`, `docs/feature_analysis_and_roadmap.md`: replace the current app name.
  `docs/implementation_plan.md` and `docs/implementation_progress.md` are point-in-time records and keep the old name.
- `CLAUDE.md`, `AGENTS.md`, `.agents/AGENTS.md`: the app name and flavor table, kept in sync.
- `CHANGELOG.md`: a new "Unreleased" entry that says the app is now called Folio. Old entries stay as they are.
- `docs/guidelines/` (submodule): not touched.

## Plan for the fix

1. Change the Android strings, `app_config.json` and `app_config.dart`. guideline.md §1.8 needs the
   launcher name and `appName` to match.
2. Change the three ARB files, run `flutter gen-l10n`, and check the label length and parity tests.
   "ഗ്രന്ഥം" and "ग्रन्थः" are well under the 22-character limit.
3. Change the Dart and Kotlin fallbacks, the log line and the comments.
4. Update the tests that expect the old name.
5. Update the docs, `pubspec.yaml`, the three rule files and `CHANGELOG.md`.
6. Run `dart format .`, `flutter analyze` (0 issues) and `flutter test`.
7. Write the change log. Flag the Malayalam and Sanskrit wording (names, store title and the
   help sentences) for native-reader review.

## Checks after the change

- `rg "SreerajP PDF"` finds the old name only in `plans/`, `change_log/`, old `CHANGELOG.md` entries
  and the point-in-time docs.
- On a phone: the launcher shows "Folio"; with the phone set to Malayalam it shows "ഗ്രന്ഥം"; the
  print service shows "Folio"; the About screen shows the new name in all three app languages.

## Security impact

This touches the Android platform folder, but only text resources and comments. It does not change
any permission, the network, storage, deep links or dependencies. The application id stays the same,
so existing installs update normally and keep their data.
