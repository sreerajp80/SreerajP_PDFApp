# Pinch-to-Zoom Gesture fix for distant fingers

**Status:** `completed`

## 1. Issue Description
Flutter's `ScaleGestureRecognizer` has difficulty transitioning from a one-finger pan to a two-finger scale if the fingers are placed far apart. In the package `pdfrx`, the viewer uses a forked version of `InteractiveViewer` where:
- If scale events start with a non-zero finger distance, they can be classified as a pan initially.
- The `ScaleUpdateDetails.scale` updates are then discarded in the pan handler if `scaleEnabled` is false or during transition stages.
- The gesture arena makes it hard for pinch-to-zoom to trigger reliably unless the fingers start very close together (at a single point).

## 2. Proposed Changes
Instead of forking the entire 84 MB `pdfrx` package, we wrap the `PdfViewer` widget in a custom `PinchZoomWrapper` widget:
- Intercept raw pointer events with a `Listener` to detect two-finger gestures.
- Calculate the scale factor and focal point manually in real-time.
- Manipulate `PdfViewerController.value` (Matrix4) directly to perform zooming.
- Disable pdfrx's internal scale gesture (`scaleEnabled: false`) to avoid double-zooming and pan conflicts.

### Files to be changed:
- `lib/features/viewer/presentation/widgets/pinch_zoom_wrapper.dart` [NEW]
- `lib/features/viewer/presentation/viewer_screen.dart` [MODIFY]

## 3. Verification Plan
- Build the app in debug mode.
- Verify pinch-to-zoom works smoothly when fingers are placed far apart initially.
- Verify scrolling and panning with one finger still work correctly.
