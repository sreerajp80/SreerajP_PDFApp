# Plan — Phase 3: Extraction & Conversion

**Status:** approval_pending

This plan describes how we will implement Phase 3: Extraction & conversion.

---

## 1. What we are building

We are adding options to extract content and convert PDFs, including:
1. **Extract Plain Text**: Extract text from a page or page range.
2. **Extract Embedded Images**: Extract raster images embedded inside the PDF (using PdfBox-Android objects).
3. **Read Form Fields**: Read any interactive Form/AcroForm fields (field names and values).
4. **Convert PDF Pages**: Render a page or range of pages to PNG or JPEG images at a selected resolution (DPI).
5. **Native Sharing**: Share the files (extracted images, text files, JSON forms) using a custom FileProvider and Android share sheet chooser, ensuring strict scoped storage compliance and offline capability with no external packages.
6. **Background Execution**: All heavy work (loading, extracting, rendering, saving) runs on background worker threads in native Kotlin, or offloaded via `compute` in Dart, keeping the UI fluent.

---

## 2. User Review Required

> [!IMPORTANT]
> - We implement File Sharing natively via platform channels using `androidx.core.content.FileProvider`. This avoids adding external packages (like `share_plus`) and potential version conflicts, keeping the app strictly offline-first.
> - Extracted files will be written to the app's cache directory (under `extracted/`), and shared. They are automatically cleared when Android cleans the app cache, meaning no stale files clutter user storage.

## 3. Proposed Changes

### Android Native Layer

#### [NEW] [file_paths.xml](file:///l:/Android/SreerajP_PDFApp/android/app/src/main/res/xml/file_paths.xml)
Configure a FileProvider resource file to share files from the app's cache directory:
```xml
<?xml version="1.0" encoding="utf-8"?>
<paths>
    <cache-path name="app_cache" path="." />
</paths>
```

#### [MODIFY] [AndroidManifest.xml](file:///l:/Android/SreerajP_PDFApp/android/app/src/main/AndroidManifest.xml)
Declare the `FileProvider` in the `<application>` block:
```xml
        <provider
            android:name="androidx.core.content.FileProvider"
            android:authorities="${applicationId}.fileprovider"
            android:exported="false"
            android:grantUriPermissions="true">
            <meta-data
                android:name="android.support.FILE_PROVIDER_PATHS"
                android:resource="@xml/file_paths" />
        </provider>
```

#### [MODIFY] [MainActivity.kt](file:///l:/Android/SreerajP_PDFApp/android/app/src/main/kotlin/in/sreerajp/pdfapp/MainActivity.kt)
Implement native file sharing in the method channel handler:
- Receive a list of file paths and an optional MIME type.
- Create `content://` URIs via `FileProvider.getUriForFile` using `${packageName}.fileprovider`.
- Trigger `ACTION_SEND` (for one file) or `ACTION_SEND_MULTIPLE` (for multiple files) wrapped in `Intent.createChooser`.

#### [MODIFY] [PdfBoxHandler.kt](file:///l:/Android/SreerajP_PDFApp/android/app/src/main/kotlin/in/sreerajp/pdfapp/PdfBoxHandler.kt)
Add the following methods running on the background thread executor:
1. `extractText(path, password, startPage, endPage)` -> Returns the raw text string.
2. `extractImages(path, password, startPage, endPage, outputDir)` -> Extracts embedded `PDImageXObject`s and saves them as PNG images, returning a list of saved paths.
3. `readFormFields(path, password)` -> Parses the AcroForm and returns a list of fields with fields: `name`, `value`, `type`, `readOnly`.
4. `renderPagesToImages(path, password, startPage, endPage, outputDir, format, dpi)` -> Renders PDF pages using `PDFRenderer` and saves them as PNG/JPEG files, returning the list of saved paths.

## 4. Verification Plan

### Automated Tests
We will add unit tests in `test/features/extraction/extraction_service_test.dart` to mock the `MethodChannel` and check:
- Correct parameters passed to platform channels.
- Error propagation and exceptions handled correctly.

### Manual Verification
1. Run the app on the device.
2. Open a test PDF.
3. Tap "Extract & Convert" from the viewer dropdown:
   - Run **Extract Text** for 1 page and multiple pages. Check that the preview works, text can be copied, and shared.
   - Run **Extract Embedded Images**. Verify it finds images and shares them.
   - Run **Convert Pages to Images**. Select PNG and check that the generated page images are sent to the share sheet.
   - Run **Read Form Fields**. Check if the form fields are detected and displayed.
4. Verify that the original PDF file remains unmodified (Copy-on-write integrity).
5. Ensure `flutter analyze` and `flutter test` are green.
